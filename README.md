# 法院短信自动化 Skill

macOS 本地法院短信材料处理工具与 Codex Skill。当前源码版本：**v0.2.0-preview**。

按短信接收日期限定范围，按送达与文书标识分别保存材料，并提供文件哈希校验、失败重试、提醒回读和人工待办。不会从 iPhone 直接拉取未同步短信。

## 使用

先阅读 [SKILL.md](SKILL.md)。基础下载层的安装方式见 [部署与配置](references/setup.md)，要求 macOS 14+、Python 3.9+ 和 Xcode Command Line Tools。原安装器仍只部署基础下载与提醒，不会自动启用新增工作流。

本次新增的 [法院文书与日历工作流](skills/court-document-workflow/SKILL.md) 包含：

- 所有文书OCR、全文审查及独立复核；默认 **GPT-6.1 Sol / max**，失败保留待办。
- 同案历次材料及短信确认双方主体；标题保留案号和具体事项，多人按每侧首名加“等”。
- 同案同日收到材料合并一条，附齐PDF；确定到期另记一条并提前7日提醒，未知到期保留待核。
- 简洁备注、附件内容回读、云端登记状态、中断后只读恢复和重复附件保护。
- 法院网页“日程”“我的案件”辅助核对；用户可另设每日9点独立聊天，读取skill不会创建定时任务。

新增模块是可审阅、可接入的源码预览，须先配置使用者自己的运行目录、日历、OCR、模型登录与法律MCP；不会继承来源机器的权限或账户，也不会自动更新已安装后台。旧式日历只保存本地文件链接；需要真实PDF附件及上述规则时按增强模块接入，并停用旧式日历写入。

## 验证

```sh
python3 tests/test_reliability.py
```

基础层包含21项隔离测试；增强模块另有Python、Node与原生附件保护测试，具体本次结果见 [VALIDATION.json](VALIDATION.json)。测试不读取真实短信或写入真实日历。尚未完成多用户、多设备和长期稳定性验证，[支持范围与验收](references/validation.md)列明限制。

## 迭代约定

- 提交源码、文档和测试；不提交配置、短信、状态、日志、案件文件或凭据。
- 修改后运行回归测试；重点验证同案同名不同送达、失败重试和日期过滤。
- 版本通过 Git tag 与 Release 发布，不自动更新使用者的后台。
- 仓库公开供下载试用与反馈，不代表对原始项目代码作无限制的开源许可授权。第三方 pypdf 按随包许可证使用。

## 归档与反馈

新送达按“周 / 案号 / 接收日期 送达（第N批） / 原文书名”保存。同一批同名文书加序号；识别码保存在隐藏清单中。未识别案号进入“待核案号”。旧版本已有送达目录继续复用，升级不会自动移动或删除历史材料。升级与回滚见 [操作说明](references/operations.md)。
