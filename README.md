# 法院短信自动化 Skill

macOS 本地法院短信材料处理工具与 Codex Skill。当前版本：**v0.1.1-preview**。

按短信接收日期限定范围，按送达与文书标识分别保存材料，并提供文件哈希校验、失败重试、提醒回读和人工待办。不会从 iPhone 直接拉取未同步短信。

## 使用

先阅读 [SKILL.md](SKILL.md) 和 [部署与配置](references/setup.md)，确认权限、接收日期起点、材料保存目录、提醒列表后再启用。要求 macOS 14+、Python 3.9+ 和 Xcode Command Line Tools。日历功能默认关闭，启用后使用本地文件链接，不是嵌入式附件。

## 验证

```sh
python3 tests/test_reliability.py
```

包含21项隔离测试；安装准备和模拟短信库补查已验证。尚未完成多用户、多设备和长期稳定性验证。[支持范围与验收](references/validation.md)列明限制。

## 迭代约定

- 提交源码、文档和测试；不提交配置、短信、状态、日志、案件文件或凭据。
- 修改后运行回归测试；重点验证同案同名不同送达、失败重试和日期过滤。
- 版本通过 Git tag 与 Release 发布，不自动更新使用者的后台。
- 仓库公开供下载试用与反馈，不代表对原始项目代码作无限制的开源许可授权。第三方 pypdf 按随包许可证使用。

## 归档与反馈

新送达按“周 / 案号 / 接收日期 送达（第N批） / 原文书名”保存。同一批同名文书加序号；识别码保存在隐藏清单中。未识别案号进入“待核案号”。旧版本已有送达目录继续复用，升级不会自动移动或删除历史材料。升级与回滚见 [操作说明](references/operations.md)。

问题和建议请提交到 [Issues](https://github.com/FakeChenMing/court-sms-automation/issues)，请先隐去案情、个人信息、文书访问链接和凭据。
